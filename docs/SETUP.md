# පිහිටුවීමේ මාර්ගෝපදේශය

මෙය කරන්නේ **එක් වරක්**, එක් අයෙක් පමණි. කාඩ්පතක් හෝ මුදලක් කිසිදු තැනක අවශ්‍ය නැත.

> සංවිධානය වෙනුවෙන් වෙනම Gmail ගිණුමක් භාවිතා කිරීම හොඳයි. එවිට දත්ත එක් පුද්ගලයෙකුගේ පෞද්ගලික ගිණුමට බැඳී නැත.

## කොටස 1 — Google Sheet එක (දත්ත ගබඩාව)

1. [sheets.new](https://sheets.new) විවෘත කර නව Sheet එකක් සාදන්න. නම: `පින් පොත`.
2. මෙනුවේ **Extensions → Apps Script** ඔබන්න.
3. එහි ඇති `Code.gs` හි සියල්ල මකා, මෙම ෆෝල්ඩරයේ `backend/Code.gs` හි සියල්ල copy කර paste කරන්න.
4. වම්පස ⚙ **Project Settings** → **"Show appsscript.json manifest file in editor"** සලකුණු කරන්න.
5. Editor එකට ආපසු ගොස් `appsscript.json` විවෘත කර, `backend/appsscript.json` හි සියල්ල paste කරන්න.
6. 💾 **Save** කරන්න.
7. Sheet එකේ tab එක **refresh** කරන්න. තත්පර කිහිපයකින් ඉහළ මෙනුවේ **පින් පොත** පෙනේ.
8. **පින් පොත → 1. මුල් සැකසුම** ඔබන්න.
   - Google අවසර ඉල්ලයි. "Google hasn't verified this app" පෙනුණොත්: **Advanced → Go to … (unsafe)** → **Allow**. මෙය ඔබේම script එක නිසා එය සාමාන්‍ය දෙයකි.
   - අවසර දුන් පසු මෙනුව **නැවත වරක්** ඔබන්න.
   - ඔබේ නම සහ ඉලක්කම් 4ක PIN එකක් ඇතුළත් කරන්න.

## කොටස 2 — Web app එක ලෙස deploy කිරීම

1. Apps Script හි **Deploy → New deployment**.
2. ⚙ → **Web app** තෝරන්න.
3. **Execute as: Me** · **Who has access: Anyone** (*"Anyone with Google account" නොවේ*).
4. **Deploy** → ලැබෙන **Web app URL** (`…/exec`) copy කරගන්න.

"Anyone" වුවත් දත්ත ආරක්ෂිතයි: දුරකථනයේ ඇති දිගු රහස් කේතය **සහ** PIN එක යන දෙකම නැතිව කිසිවක් කියවිය නොහැක. වැරදි PIN 5කින් ගිණුම තාවකාලිකව අගුළු වැටේ.

## කොටස 5 — පළමු දත්ත (app එකෙන්)

1. **තවත් → සැකසුම් → සංවිධානය**: නම, බැංකු විස්තර.
2. **තවත් → සාමාජිකයන් → ලැයිස්තුවක්**: 100 දෙනාම එකවර paste කරන්න (`නම, දුරකථනය, ප්‍රදේශය`).
3. **තවත් → පින්කම්**: "ඉදිරි පොහොය දින එක් කරන්න". සංවත්සර පින්කමත් එක් කරන්න.
4. **තවත් → අත ඇති මුදල් → මුල් ඉතිරිය**: පොතේ දැනට ඇති ඉතිරි මුදල, අරමුදල් දෙකටම.
5. **තවත් → පවුල්**: පවුල් සහ ප්‍රදේශ.

## Excel ලෙස බැලීම

Sheet එකේ **සාරාංශය, පරිත්‍යාග, වියදම්** යන tabs ඉබේම යාවත්කාලීන වේ. Excel ගොනුවක් ලෙස: **File → Download → Microsoft Excel**.

⚠️ `db_…` tabs (සඟවා ඇත) **අතින් වෙනස් කරන්න එපා**. වාර්තා tabs වල අතින් ලියන දේ ඊළඟ update එකේදී මැකේ. වෙනස්කම් app එකෙන්ම කරන්න.
